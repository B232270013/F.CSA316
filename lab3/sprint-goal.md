# Sprint Goal

> Хэрэглэгч профайлтай бүртгэл үүсгэж, найз нэмэн, ивент үүсгэж, сонгосон найзуудаа урих болон оролцоогоо (RSVP) баталгаажуулах MVP урсгалыг бэлэн болгох.

## Хэмжигдэхүйц амжилтын шалгуур

- Шинэ хэрэглэгч бүртгүүлж, profile мэдээллээ хадгалж чадна.
- Хэрэглэгч username эсвэл утасны дугаараар найз нэмж чадна.
- Хэрэглэгч гарчиг, тайлбар, огноотой ивент үүсгэнэ.
- Зохион байгуулагч ивентэд найзуудаа урьж, уригдсан жагсаалтыг харна.
- Уригдсан хэрэглэгч Going, Maybe, Not going гэсэн RSVP сонголт өгнө.
- Хэрэглэгч ивентэд сэтгэгдэл бичиж, сануулах мэдэгдэл авч чадна.
- Сонгосон Sprint Backlog 20 SP-ийн ажлууд Done шалгуурыг хангасан байна.

## Done шалгуур

1. User Story-ийн хүлээн авах шалгуур биелсэн.
2. Үндсэн урсгалын тест амжилттай.
3. Form validation болон алдааны мэдэгдэл ажиллана.
4. Багийн дотоод код хяналт хийгдсэн байна.
